# ALIEVA LAW

Рабочий сайт адвоката Алиевой Эльмиры Ханоглановны под GitHub и Vercel.

## Vercel

Framework: Vite
Build command: npm run build
Output directory: dist
Install command: npm install

## Заявки

Форма отправляет POST-запрос на /api/contact.
Если в Vercel добавить переменные TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID, заявки будут уходить в Telegram.

# ALIEVA LAW

Сайт адвоката Алиевой Эльмиры Ханоглановны под Vercel.

## Локальный запуск

```bash
npm install
npm run dev
```

## Деплой на Vercel

1. Залейте все файлы из архива в корень GitHub-репозитория.
2. Подключите репозиторий в Vercel.
3. Настройки:
   - Framework Preset: Vite
   - Install Command: npm install
   - Build Command: npm run build
   - Output Directory: dist
4. Нажмите Deploy.

## Структура

- `src/App.jsx` - основная страница
- `src/data/siteData.js` - тексты, услуги, SEO-страницы
- `src/components` - переиспользуемые компоненты
